Mes alertes Algo et Safe

Une proposition à vérifier, puis une validation par toi sur Winamax. Aucun pari n’est passé par cette application.

Recevoir les alertes, même téléphone verrouillé

Les notifications passent par l’application gratuite ntfy, à installer sur ton iPhone ou Android. Les sélections publiques seront transmises à ce service. Aucun identifiant Winamax ni historique personnel n’est envoyé.

  1. Installe ntfy, puis génère ci-dessous ton canal privé.
  2. Dans ntfy, abonne-toi à ce canal sur le serveur https://ntfy.sh.
  3. Dans GitHub, ouvre combi-du-jour → Settings → Secrets and variables → Actions → New repository secret. Nom : NTFY_TOPIC. Valeur : le canal généré.

Ce canal est un secret : toute personne qui le connaît peut lire ou envoyer des alertes. Ne le publie pas et ne l’ajoute pas aux fichiers du dépôt.

Les alertes suivent la collecte quotidienne, vers 7 h 05 en hiver / 8 h 05 en été, heure de Paris (GitHub peut retarder l’exécution). Un lancement manuel du workflow peut aussi les déclencher. Aucun ticket absent, commencé ou fondé sur un relevé de plus d’une heure n’est envoyé.

Le test vérifie le canal depuis cet appareil ; il ne prouve pas que le secret GitHub est configuré. Tu peux retirer NTFY_TOPIC de GitHub pour arrêter les envois. Désabonne-toi aussi dans ntfy. Le journal des mises fictives continue séparément.
